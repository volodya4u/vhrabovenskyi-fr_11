## Prerequisites

* Node 22.15 or newer
* npm 10 or newer

Webpack and the rest of the build tools are installed locally with the project.

## Usage

* `npm install` downloads all dependencies.
* `npm run dev` starts the development server at `http://localhost:8080/`.
* `npm run build` compiles and minifies the app into the `dist` folder.
* `npm run lint` lints the source and build configuration.
* `npm test` runs the Jasmine tests in Chrome Headless.
